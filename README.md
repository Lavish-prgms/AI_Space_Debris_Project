# AI Space Debris Detection System 🚀

A smart AI-powered system for detecting space debris from images and monitoring orbital threats through an interactive dashboard.

## 📌 Project Overview

Space debris has become a serious issue in Earth’s orbit due to the rapid increase of satellite launches, non-functional satellites, rocket fragments, and broken particles. These objects move at high speed and can damage active satellites, communication systems, and future missions.

This project provides an intelligent and low-cost solution that detects and classifies space objects such as:

- Space Debris  
- Satellites  
- Planets  

using image processing and AI-based detection logic.

---

## ⚙️ Technologies Used

- Python  
- Streamlit  
- OpenCV  
- NumPy  
- Pandas  
- Pillow  
- Ultralytics YOLO (optional advanced model)

---

## 🎯 Features

- Upload space images  
- Detect objects automatically  
- Classify debris / satellite / planet  
- Bounding box detection  
- Object count summary  
- Smart dashboard interface  
- Risk monitoring report  

---

## 🖥️ Dashboard Modules

- Total Objects Count  
- Debris Count  
- Satellite Count  
- Planet Count  
- AI Detection Output  
- Detection Report Table
